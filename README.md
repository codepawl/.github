# .github

Default community-health files for the CodePawl GitHub organization.

- [`profile/README.md`](profile/README.md) — organization profile page
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — organization-wide contribution guide
- [`SUPPORT.md`](SUPPORT.md) — how to get in touch
- [`SECURITY.md`](SECURITY.md) — vulnerability reporting
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) — organization-wide community standards
- [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) — default issue forms and contact routes
- [`pull_request_template.md`](pull_request_template.md) — default PR template for org repos
